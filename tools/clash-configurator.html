Clash Configurator

Builds two [ClashEngine] blocks side by side: plug-in tuning for conf/global.conf, and the game types + queues for an arena's arena.conf. Game types and queues are arena-scoped — the engine ignores them if they appear in global.conf.

Plug-in tuning (global.conf)

Default queue (per-arena)

▾

Goes in an arena's arena.conf. Sets what ?play resolves to from that arena when no queue is named.

Must match a queue defined below.

Game types

▾

A game type is the rules of one match shape. Game types live in this arena's arena.conf, but their names are globally referenceable: a Queue<i>GameType in any arena can reference one by name. A name is owned by its first declarer for the server's lifetime (sticky, even after the arena detaches), so declare each name once.

Queues

▾

Each queue is one matchmaking pool that produces matches under a particular game type. Queues live in this arena's arena.conf.
