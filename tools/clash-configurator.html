Clash Configurator

Builds two [ClashEngine] blocks side by side: one for conf/global.conf (engine-wide settings) and one for an arena's arena.conf (per-arena settings). Each game type and queue picks which file it belongs in.

Plug-in tuning (global.conf)

▾

Engine-wide settings. Only non-default values are emitted.

Default queue (per-arena)

▾

Goes in an arena's arena.conf. Sets what ?play resolves to from that arena when no queue is named.

Must match a queue defined below.

Game types

▾

A game type is the rules of one match shape. Each card's Global / Arena toggle decides whether it lands in global.conf (visible to every arena) or this arena's arena.conf.

Queues

▾

Each queue is one matchmaking pool that produces matches under a particular game type. Use the Global / Arena toggle to choose which conf file the queue lands in.
